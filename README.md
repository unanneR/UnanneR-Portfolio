# Developer Portfolio | Unanne Radzuma

A responsive, minimal, and high-performance developer portfolio built to showcase full-stack applications, software architecture, and network security projects. Designed with a focus on editorial typography, clean user experience, and semantic web standards.


---

## 🌟 Key Features

- **Editorial UI/UX Design:** High-contrast typography paired with a clean, grid-aligned design system.
- **Interactive Project Archive:** Folder-style navigation displaying project scope, tech stack, key takeaways, and direct repository links.
- **Dynamic Contact & Social Hub:** Streamlined contact interface with direct email action and social links (GitHub, LinkedIn, Discord, CodePen).
- **Fully Responsive & Accessible:** Built with semantic HTML5 markup, WCAG-compliant contrast ratios, and accessible SVG icon sets.

---

## 🛠 Tech Stack

- **Frontend:** HTML5, Modern CSS3, Vanilla JavaScript
- **Styling Highlights:** CSS Grid, Flexbox, Custom CSS Variables, Fluid Typography
- **Icons & Assets:** Optimized Inline Vector SVGs

---

## 📂 Featured Projects in Portfolio

1. **C# & .NET Systems:** Enterprise application architectural patterns, RESTful APIs, and scalable C# backend code.
2. **UbuntuExchange Marketplace:** Full-stack C2C e-commerce platform built with PHP, MySQL, and custom security/escrow workflows.
3. **Task Tracker & Automation:** Specialized scripts and background utility systems.
